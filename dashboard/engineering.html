FIELD GUIDE

How to use the Engineering Lab.

Each panel is a direct window into repository components; connect the local services you need before running them.

01

Start locally

From the repository root, run uv run python dashboard/server.py. Keep the API on localhost; it is not authenticated for public hosting.

02

Explore tools safely

Select a real MCP server and inspect its discovered tool signatures. Calls use repository tools directly; WO tools are read-only and FMSR edits are excluded.

03

Compare and evaluate

Pick a scenario and two to four runners. Agent outputs use real model/MCP calls; LLM-As-Judge runs only when the scenario includes a reference answer.

04

Understand batch limits

Profiles come from the benchmark YAMLs, but only locally discovered scenarios are run here. A batch is capped at 20 scenarios and does not reset CouchDB.

Configure model-provider credentials and any required data services in the server environment. Never put secrets in browser code or commit them. Runs can incur API costs; tool, dependency, and data-service errors are displayed as returned or raised by the repository.
